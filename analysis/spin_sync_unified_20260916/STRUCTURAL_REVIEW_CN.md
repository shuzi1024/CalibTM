# 统一模型的结构性评语（完整结果尚未形成）

2026-09-16。依据本地 [METHOD_CN.md](METHOD_CN.md) 与 [models.py](../../experiments/spin_sync_unified_v1/models.py) 作出的结构推断。当前仅 Abilene seed41001 的配对完成；不据此给最终评分，不启动实验或改变既定八条 120 轮安排。

1. **存在职责重叠。** SPIN 已对本流和相关邻流的整窗可见数据进行时间／空间聚合；Sync 随后又沿相同目标邻域读取这些上下文。因此不能简单讲成“SPIN 负责空间、Sync 负责时间”：前者已经包含时间建模，后者的每次写入也已经含有整窗信息。两条路径都承担目标位置的上下文汇总，可能出现边际收益减小，但这是待验证解释。

2. **重叠不等于数学等价。** 对目标流 i，SPIN 的 H_i 来自一跳邻流；Sync 读取邻流 j 的 H_j 时，还可能间接读取 j 的邻居，即条件性的两跳信息。其 K/V 变换、矩阵残差更新和按查询读出也不同于原注意力求和。新增分支可能扩大有效信息范围或改变压缩方式，不能仅凭结构图断言它必然冗余。只有可见源位置写入，具体扩展仍受图与掩码限制。

3. **no_memory 是有完整上下文的强对照。** 它保留 `H_target → Q → decoder`，同时保留 Direct 的原始近邻值。因此删除记忆并未删除 SPIN 的跨流信息，也未切断可见值到输出的主要路径。若它达到同等效果，能直接说明当前解码任务可能不需要额外矩阵状态；反之，Full 的优势也不能误写成“有跨流信息优于没有跨流信息”。

4. **Sync 的必要增量须由完成的配对结果支持。** 两个 WAN、两个初始化的既定结果完成后，Full 相对 no_memory 的主要 NMAE 应出现可重复、可解释的收益，并同时交代条件差异、NRMSE 和新增成本。无需要求所有格子都获胜，也不设临时提升百分比门槛；但只有某个种子或某个次要指标获胜，不足以支持稳定增量。当前 Abilene seed41001 的 0.162975999 对 0.163432869 是一个正向信号，不能替代尚未完成的其他配对。

5. **即使 Full 胜出，也只先归因于新增分支整体。** Full 同时增加参数、上下文变换、潜在两跳信息和递归状态；no_memory 不控制这些因素各自的作用。现有最小对照足以判断这个分支是否值得保留，不足以证明“同步更新本身不可替代”或优于其他等容量聚合器。本轮无需为更强的机制措辞追加大量消融，收窄主张即可。

6. **若最终没有稳定增量，最简单方向是移除 Sync，围绕已有 no_memory 收敛。** 明确问题变为：一层 SPIN 上下文与原始局部值通路，能否以更简单的完整系统提供有竞争力的补全？先使用本轮已经完成的 no_memory 与 SPIN／Linear 结果及成本回答，不另起模块搜索，也不退回此前的冻结输出适配器。如果这个简化系统也缺乏竞争力，就结束本次组合方向；保留三种模块的名称不应成为继续复杂化的理由。

7. **失败原因仍需保持未定。** 若 Sync 无增量，职责重叠、参数增加带来的优化难度、现有窗口／掩码下没有足够剩余信号，都只是可能解释；当前结构分析不能区分它们。先按原安排完成八条 120 轮结果，再判断是否保留分支；不据中间分数更改模型、追加结构或宣称已经定位失败机制。
