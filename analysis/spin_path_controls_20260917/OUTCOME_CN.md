## 2. 主结果：开发 NMAE，越低越好

三个条件等权、两个初始化的均值 ± 样本标准差。160轮按既定最佳检查点规则选择；标准差不是置信区间。

| 模型 | Abilene | GEANT |
|---|---:|---:|
| **SPIN＋Direct** | **0.161358 ± 0.001169** | **0.164810 ± 0.000562** |
| Context-only | 0.164053 ± 0.000697 | 0.168494 ± 0.001417 |
| Direct-only | 0.165011 ± 0.000010 | 0.172246 ± 0.003507 |

组合相对Context-only改善 **1.64% / 2.19%**，相对Direct-only改善 **2.21% / 4.32%**（Abilene / GEANT）。120轮截面也具有相同排序；两个预算中，全部种子和条件的NMAE均支持组合。

在最终160轮比较的八个“WAN×种子×控制模型”配对中，组合最后20轮的每个分数均优于对应控制模型的全程最佳分数。因此结果不依赖孤立最好点。轮次相关，这个诊断不能算作更多独立重复或统计显著性；160轮也不等于充分收敛。

完整数值见[结果表](DATA_TABLES_CN.md)、[GEANT汇总](summary/SUMMARY_CN.md)、[Abilene汇总](summary_abilene/SUMMARY_CN.md)。两个预算、全部种子、逐条件记录和预定义分组均保留。

## 3. 成本和误差取舍必须同时保留

同一张H20测量各模型完整推理；下表为三个条件中位耗时的平均。B8是每窗摊销，非单请求延迟。

| 数据 | 模型 | B1 ms | B8 ms/窗 |
|---|---|---:|---:|
| Abilene | SPIN＋Direct | 9.722 | 6.142 |
| Abilene | Context-only | 8.349 | 5.916 |
| Abilene | Direct-only | 3.070 | 0.521 |
| GEANT | SPIN＋Direct | 22.531 | 18.996 |
| GEANT | Context-only | 21.658 | 18.359 |
| GEANT | Direct-only | 3.122 | 1.155 |

- 相对Context-only，Direct增加1,440个名义参数；B8耗时增加 **3.82% / 3.47%**，峰值已分配显存几乎相同。但B1增加 **16.45% / 4.03%**，不能笼统称所有场景只多约4%成本。
- 相对Direct-only，组合B8耗时为 **11.79 / 16.45倍**。需要吞吐优先时，较简单路径仍有实际价值。
- 条件平均NRMSE在两个WAN、两个种子上均优于两个路径对照；但GEANT相对Direct-only的不均匀/共享缺口NRMSE均略差。
- GEANT相对Context-only，在不均匀/共享缺口的单侧观测边界NMAE也略差。不能宣称所有观测支持类型都改善。
- 相对历史同掩码Linear，NMAE改善 **5.65% / 1.75%**；GEANT的NRMSE仍差 **0.42%**。Linear的CPU成本已补测，设备与边界分别标注，不作跨设备加速比宣称。

Full原120轮的NMAE缺乏稳定收益，但条件平均NRMSE改善约0.86%/1.24%，原B8成本增加约64%/62%。这些旧结果全部保留；Full未参加本轮160轮诊断，不能据新旧预算交叉比较断言记忆机制普遍无效。

## 4. 方法定位与下一步

当前方法：一层SPIN从当前窗口的真实可见输入构造上下文；Direct绕过上下文，读取本流前后各至多两个最近真实观测，分别提取加权数值、距离和可用性三个量；两方向统计量的投影与上下文查询拼接解码。整窗和双向读取使其属于离线补全。

Direct提供的是一条受约束的局部读出路径。每方向的128维向量来自无偏置3→128投影，秩至多3；它没有引入SPIN原本无法访问的观测，也不保证保幅复制。当前对照支持这条路径在该骨架与预算下的使用价值，没有单独证明某一种机制或排除所有替代浅层解码设计。

**下一阶段保留一个有限的确认任务。** 先固定候选、训练配方、检查点与评价清单，核实评估来源；然后与Linear、正常工作的SPIN、旧Direct＋Sync和一个相关的SRMF＋邻近观测补正参考公平比较，并补齐可执行的数据/训练/评价入口。

本轮没有取得经审计确认、此前未参与项目决策的新流量来源。若后续只能复用历史数据，应明确称为冻结后复核；新掩码不是新流量样本。此阶段尚未启动，不能将本轮组件对照当作已经完成公平外部确认。

不需要再扩张融合设计、层数、观测率或组件消融矩阵。[相关工作核验](RELATED_WORK_CHECK_CN.md)已补入TM-LLM与Utimac的准确定位，未据不同协议的论文数字建立优劣结论。
