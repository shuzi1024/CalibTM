# 固定两步细化实现审阅

审阅日期：2026-09-17。本记录是独立的静态代码审阅，不是运行复现认证。审阅时 **CPU 语义检查仍待执行，GPU smoke、正式训练和成本测量均未运行**。

## 范围与结论

核对 `experiments/spin_refine_v1/models.py`、`runner.py`、`summarize.py`，以及本目录的计划、启动器与成本脚本；对照原 SPIN＋Direct 模型、SPIN 注意力实现及训练引擎。未修改历史模型、结果或论文。

**没有发现模型信息流或训练计算的阻断性错误，可以进入既定 CPU 检查。** 此结论不代表两步方法能够改善误差，也不构成开始 GPU 工作的授权。

## 模型信息流

- 上下文可用掩码与原始真实观测掩码分开。第一步仅允许真实观测作为消息源；第二步的标准化、编码选择、数值跳接和注意力均允许回填窗口参与，估计不会在编码前被原始掩码清掉。
- 原始真实观测标记作为数值编码器的第二输入保留，区分真实值与暂估值。该标记由模型学习使用，不保证消除误差传播。
- Direct 始终根据原始观测值和原始掩码计算，并缓存供两步复用。暂估值不能进入 Direct。
- 第一步生成完整流图的暂估值，即使只请求部分目标流，也不会改变第二步的邻流输入。最终解码才选择目标流。
- 两步复用同一编码器、查询与解码器；缺失处回填第一步的非负估计，观测处保留原值。代码没有跨步 `detach`。
- 扩展输入线性层发生在原模型构造之后，正确复制旧数值列和偏置，将新增的 32 个来源标记权重置零。一步与两步的参数集合和初始化一致。首步与旧模型的输出兼容检查应允许合理 FP32 容差，不能因输入矩阵宽度变化而强求输出逐位一致。
- 只有最终缺失项损失，没有首步独立监督。因此首步应称“暂估值”，不能预先声称它是有效的粗补全结果。本实现是同分辨率迭代细化，不是 ARI 多分辨率自回归或 LLM 的复现。

## 训练、汇总与成本

- 两个新版本均从头训练，采用全目标 batch 8，避免按目标块反复执行整图两步计算。
- 固定 120＋40 轮与一次学习率下降；完整轮次提交，恢复优化器和随机状态；120 轮快照后恢复末轮状态；最佳检查点重新加载后核对开发评分。
- 汇总要求 GEANT 四条轨迹全部完成，核对配对初始化、数据、配方与掩码顺序，同时报告最佳主指标和末 20 轮中位数方向。后者只是相关轨迹诊断，不是独立重复。
- 原 SPIN＋Direct 作为历史参照保留。一步／两步比较匹配样本曝光和更新次数，不匹配计算量；成本脚本计入完整推理的两次上下文处理，并在同卡比较 B1、B8。
- 两步未在两个种子的主 NMAE 与末段趋势上同时优于新一步时，按计划停止，不搜索门控、步数或额外损失。即使筛选通过，外部基线公平性与独立评价缺口仍未解决。

## 已修正的启动问题

初审发现启动器的 `--worker` 分支先于授权、CPU 检查和源码冻结验证。修订后，这些公共验证已移至分支之前，worker 另行检查 `CUDA_VISIBLE_DEVICES` 与所选 GPU 一致；已复核修正代码。正式执行仍须使用本轮有效 GPU 授权，不能沿用已过期授权。

## 后续运行检查边界

既定 CPU 检查应覆盖：配对初始化、隐藏真值与输入梯度隔离、暂估值确实影响第二步、Direct 不受回填影响、观测严格回写、跨步梯度、目标分块一致、空观测有限及状态重载。上述检查通过后，方可在有效资源授权内执行拟合窗口 smoke 与四条正式训练。本记录不预报这些检查或实验的结果。
