# Tiny-KAN 一次性碰撞实验：正式中文结项报告

> 日期：2026-08-11  
> 协议：`tiny-kan-calibrator-v1`  
> 证据角色：post-project one-shot development collision；不是独立确认  
> 最终状态：**`KILL_TINY_KAN_KEEP_VALUE_ONLY`**

## 0. 一页结论

本轮把当前 5,475 参数 `value_only` bounded calibrator 中的 MLP logit map，整体替换为唯一冻结的 5,539 参数 cubic B-spline Tiny-KAN；Linear scaffold、输入信息、输出约束、训练预算和数据边界全部保持不变。18/18 个注册作业一次成功后，冻结 adjudicator 得到：

| 对比 | 等数据集权重 structured gain | 95% paired block-bootstrap CI | Abilene | GEANT | 裁决 |
|---|---:|---:|---:|---:|---|
| `kan_value` vs `mlp_value` | **−0.01612%** | **[−0.02892%, −0.00346%]** | −0.03093% | −0.00131% | FAIL |
| `kan_value` vs `kan_static` | **+0.83094%** | **[+0.69764%, +0.98428%]** | +1.42749% | +0.23439% | PASS |

一句话解释：**样本相关的 value conditioning 在同构 KAN control 下仍有价值，但 KAN 函数参数化没有给当前 MLP 带来任何 material headroom，反而在本 development cohort 上出现极小而稳定的负差。**

因此，必须按预注册规则执行：

```text
KILL_TINY_KAN_KEEP_VALUE_ONLY
```

不运行 zero-spline attribution，不运行正式 latency/memory gate，不尝试其他 KAN 变体，也不围绕 GEANT 的少数局部正单元调参。现有论文主线不变：**冻结 `value_only`，继续完成 constrained-calibration / accuracy–efficiency 定位的 CCF-C 论文写作。**

## 1. 为什么做这次实验，以及它没有解决什么

### 1.1 场景和已有证据

目标场景是极端时间稀疏下的离线 WAN Traffic Matrix repair：每条长度 `T=50` 的轨迹通常只保留 `K=3` 个真实观测，缺失既可能随机发生，也可能形成内部连续 gap 或 two-burst。场景要求是：已观测值原样保留、缺失预测非负、利用极少观测定义的 canonical Linear scaffold 而避免无约束自由重建，并在准确率与成本之间提供合理 operating point。当前 `value_only` 的主路径为：

```text
真实观测
  -> canonical Linear scaffold
  -> observation-conditioned bounded calibration
  -> observed hard-copy + non-negativity
```

它不是给 ARI-LLM 增加支路，而是用一次前向、低自由度、锚点保持的补全算子替换 LLM/Flow2Vec/自回归主干。既有 matched evidence 支持 observation-conditioned calibration，并把主要可测收益定位到 bounded internal / edge offsets。

### 1.2 Tiny-KAN 的真实研究身份

本轮只检验一个窄问题：

> 在信息、Linear scaffold、可行输出空间和参数量近似匹配时，edge-wise cubic B-spline KAN 是否比当前 MLP 更适合学习 16 维条件特征到三个 bounded calibration logits 的低维映射？

动机是：如果有用修正是一条局部平滑的低维 deformation law，可学习的一元样条边函数或许更匹配这个函数族。但项目**没有** oracle、残差复杂度或函数形状证据证明 MLP expressivity 是当前瓶颈。因此它不是从已证实痛点自然推出的新主方法，只是“热门模块若有效也可采纳”之后的一次受控 collision；通过或失败都不能自动构成深入创新。

## 2. 冻结方法和 matched controls

### 2.1 唯一模型替换

唯一变化是将 `LayerNorm(16) → Linear(16,64) → GELU → Linear(64,64) → GELU → 3 heads` 整体替换为 `LayerNorm(16) → KAN(16,32) → KAN(32,3)`。每条输入—输出边为：

```text
phi(x) = w_base * SiLU(x)
       + sum_{i=1..8} c_i * B_i(tanh(x/2))
```

固定实现是 order-3 cubic B-spline、range `[-1,1]`、5 个 grid intervals、每边 8 个 basis；uniform grid 在两端按 order 等距扩展且不学习；spline/base branches 分别使用 `tanh(x/2)` 和原值 SiLU；低精度输入时 LayerNorm、basis recursion 和 contraction 显式用 FP32；第二层 near-zero 初始化。三个输出仍进入冻结的 `delta-r`、internal-offset、edge-offset 有界方程。

### 2.2 外层保持不变

保持不变的部分包括：`value_only` 16 维 feature mask、normalization、hidden-truth exclusion、canonical Linear 和 edge rule、三组 beta、`tanh`/clipping/anchor-scale 方程、hard copy、non-negativity、K3/K2 objective、训练预算和数据/seed/mask registry。KAN 不自由预测整张 TM，也不是无界 Linear residual；它只替换原可行输出空间内的三个 logit 映射。

### 2.3 三个 arms 与参数量

| Arm | 学习映射 | 输入条件 | 参数量 | 作用 |
|---|---|---|---:|---|
| `mlp_value` | 原冻结 MLP | `value_only` 特征 | 5,475 | matched incumbent |
| `kan_value` | 唯一 Tiny-KAN | 相同 `value_only` 特征 | 5,539 | 检验 KAN 相对 MLP 的函数族价值 |
| `kan_static` | 与 `kan_value` 完全同构 | 16 通道代数置零 | 5,539 | 检验样本条件化而非参数/初始化效应 |

Tiny-KAN 比 MLP 多 64 个参数，即 `+1.169%`，满足注册的 ±5% 参数匹配范围。因此不能宣称 Tiny-KAN 参数更少。

## 3. 证据协议和裁决规则

闭合网格为 `2 datasets × 3 seed bundles × 3 arms = 18 jobs`。每个 job 都评估 `random`、`internal_block` 和 `two_burst`；headline structured 指标合并后两类。checkpoint 只由 pooled source-dev NMAE 选择，最终统一在已经消费过的 `tune` 上裁决。

Relative gain 定义为：

```text
Gain(candidate, comparator) = 1 - NMAE(candidate) / NMAE(comparator)
```

因此正值表示 candidate 更好，负值表示 candidate 更差。headline 在每个 dataset×seed 内用 structured error ratio-of-sums，再对 seed 等权、对 dataset 等权。置信区间采用 seed 外层重采样和时间窗口 moving-block bootstrap：10,000 draws、PCG64DXSM、seed `2026081107`、block length `4`。

`kan_value` 相对 MLP 必须同时满足：至少 +1% headline、CI lower > 0、两个数据集均为正、至少 2/3 seed bundle 为正，以及 structured/random harm guards。`kan_value` 相对 `kan_static` 还必须同时满足至少 +0.5%、CI lower > 0、两个数据集均为正。任何一项失败就 kill。

本轮不是 sealed-test、project-wide pristine 或 fresh independent confirmation，也不足以单独替换论文 incumbent。

## 5. 为什么立即 kill，而不是继续调 KAN

注册的 material threshold 是 `+1%`，实际 headline 是 `−0.01612%`；两个数据集均不为正，三个 seed bundle 均不为正，CI 也完整落在 0 以下。GEANT/random 等少数 `+0.02%` 到 `+0.05%` 的局部正值远低于 practical threshold，而且被其他 masks/seeds 反转。

因此继续围绕这些 cell 选择 grid、order、宽度、深度或新 KAN 变体，会把一次闭合碰撞退化成 outcome-driven validation search。

zero-spline replay 和正式 latency/memory 都只在 accuracy PASS 后运行。本轮无正收益可归因，也没有候选方法身份；adjudication 明确记录 `latency_gate_pending_only_if_accuracy_proceeds=false`。预正式 smoke 中 KAN peak reserved 为 3,902 MiB、MLP 为 332 MiB，但它只有一次 optimizer update，且没有为 timing 做 warm-up/counterbalancing，所以只证明 arithmetic、gradient 和 feasibility 可运行，**不是**正式效率结论。

Research Card 也预先禁止 FastKAN、ChebyshevKAN、RBF-KAN、FourierKAN、WavKAN，以及改 grid/order/width/depth、learned grid、gate、router 和 auxiliary loss。项目没有新证据说明其中任何变体对应已识别的 TM repair 痛点。

正确的科研动作不是让热门模块活下来，而是让 matched evidence 决定它应当死亡。

## 6. 与 KAN / TimeKAN 的文献边界

[Liu et al., “KAN: Kolmogorov–Arnold Networks,” ICLR 2025 Oral](https://openreview.net/forum?id=Ozo7qJ5vZi) 已经提出用边上的可学习一元函数替代 MLP 的固定节点激活/可学习边权重，数值实现也已包含 SiLU base、B-spline expansion 和逐层 KAN 组合。因此 edge-wise functions、cubic splines 和“用 KAN 替换 MLP”均不是项目创新。

本实现也不是官方 `pykan` 的完整忠实复现：它没有 adaptive grid、sparsification、pruning、可视化、symbolic branch 或 sweep；它加入了任务内 domain map、fixed knots、FP32 spline arithmetic、near-zero output initialization 和外层 feasibility constraints。准确称呼是“任务约束下的 fixed Tiny-KAN transplant”。

[Huang et al., “TimeKAN,” ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/46362971bfc3a97e6a271f2eb90fba17-Paper-Conference.pdf) 已经把 KAN 用于时间序列预测，并设计 frequency decomposition 与 multi-order KAN。因此无论结果正负，本项目都不能宣称 first KAN for time series、first lightweight KAN temporal model，或把 KAN 本身当作 TM repair 的 novelty。

本轮也没有 edge visualization、pruning、symbolification 或人类可读公式验证，不能宣称“可解释”；不能从 Kolmogorov–Arnold representation theorem 推导本任务上的最优性、泛化或样本复杂度；不能把本次固定 transplant 的 FAIL 外推成“KAN 普遍无效”。

## 7. 对导师建议与二阶 auto-research 的复盘

导师要求的核心是：先从困难场景和明确痛点出发，理解为何现有方法在该场景下不足，再设计能够解释清楚的方法，而不是调一部分参数或增加小组件换取性能。

### 7.1 本轮做对的地方

1. 场景没有漂移：仍是 K=3/50、structured gaps、硬锚点、非负和低成本 offline repair。
2. 不是给 ARI-LLM 做加法：整体替换 logit map，没有 residual、gate、router、memory 或 selector。
3. matched controls 区分了 conditioning 与 KAN 函数族，前者的正结果不能掩盖后者失败。
4. 18/18 后一次裁决，没有因局部正 cell 修改模型或启动 sweep。

这些做法摆脱了第一层 auto-research：不是在旧主干上不断堆小模块。

### 7.2 本轮仍有的二阶 auto-research 风险

这次选择 KAN 的主要理由仍是“热门且似乎适合平滑低维映射”，而不是证据先证明 MLP 表达能力不足、correction law 具有 KAN 独特适配的形状，或 spline edge functions 改变了信息/可行域。因此即使点估计略好，也只会是模块碰撞，不会自动形成深层 insight。它没有增加论文 novelty；其价值是确认：**不能用热门 backbone replacement 为当前论文制造方法身份。**

本轮摆脱二阶 auto-research 的关键，不是协议有多少 hash 和 gate，而是结果出来以后真的停止：不把 `+0.83094% vs static` 偷换成“KAN 有效”，不追 GEANT 局部正值，不生成 Tiny-KAN v2。

### 7.3 对后续工作的约束

若没有由场景证据支持、且改变输出可行域、信息组织或任务定义的新问题，就不再开启架构搜索。论文 insight 应放在 `free reconstruction → constrained calibration around an explicit feasible prior`，而不是 MLP、KAN 或其他通用模块。

## 8. 对论文主线的实际影响

本实验不会成为新论文主方法，也不改变 incumbent。后续冻结 `value_only`，停止 backbone search，继续以极端时间稀疏 offline TM repair 为场景写 CCF-C 方法论文。方法章节强调 hard anchor preservation、bounded deformation、non-negativity 和 observation-conditioned calibration；实验诚实呈现 Linear、static control、ARI-LLM、ImputeFormer、A/G/BRAIN、observation-rate 和 pipeline efficiency。Tiny-KAN 只保留为内部 negative collision record，至多在 appendix 简述，不能包装成主贡献。

审稿人最可能的 novelty 质疑仍是“linear interpolation + tiny MLP correction”。解决方式不是再加 KAN，而是把论文核心讲清为：**在强 scaffold 和极少真实 anchors 已经限定问题时，主动限制输出自由度，比让高自由度模型自由重建更合适。** 这一 claim 必须由现有约束性质、matched static control、跨数据集结果和 accuracy–efficiency Pareto 共同支撑。
