## 一句话结论

> 这两个月我围绕您之前关于 auto-research 和有效进度的批评做了三步收敛：先用可否定实验停止没有稳定收益的复杂模型路线，再把问题收窄为“Linear 已经很强时，能否只用一个很小的模型做有限修正”，最后固定 5,475 参数的 CalibTM，完成同参数公平对照、三个 WAN、ARI/ImputeFormer 对比、统计复核和 CPU/H800 成本测试。现在方法搜索已经停止，下一步是正式成稿，而不是再试模型。

## 建议的 6 页汇报结构

### 第 1 页：暑假两个月怎样从发散走向收敛

只讲三件事：

1. **诊断阶段：** 识别出早期并行尝试多个模块、问题—机制—实验不闭环的 auto-research 倾向。
2. **收缩阶段：** 用正式负结果停止匿名 cross-flow、query/prior placement 和热门函数参数化替换三类复杂路线；固定信息边界、场景和否定标准，负结果不再用新模块“救”。具体实验代号只放 backup，不在主线逐个展开。
3. **验证阶段：** 只保留有稳定证据的最小方法，固定模型后，转向公平对照、第三个 WAN、统计和计算成本验证。

不要说“我一开始就是从真实痛点推导出 CalibTM”。诚实时间线是：它先在系统收缩中幸存，后经 problem-first 审计和新证据验证、限定。

### 第 2 页：问题与方法

场景：离线 WAN TM archive repair；长度 50 的窗口内，每条 flow 只有 3 个可信锚点；不使用 topology、routing 或持久 flow identity。

痛点：Linear 已经是一条很强、且不需要训练的初始曲线；大型模型成本高，而且换一个网络后不一定仍然更好。

方法：

```text
K=3 observed anchors
        ↓
observation-only canonical Linear
        ↓
5,475参数的小模型做有限修正
        ↓
internal point / boundary-segment correction
        ↓
hard-copy observed anchors + nonnegative output
```

定位：不是发明 interpolation，也不是新型 MLP；贡献是在这个特定场景中，找到并验证了一种精度和成本之间的合理折中。

### 第 3 页：最干净的核心证据

主对照不是只比大模型，而是一个参数量、初始化和训练次数都相同的静态校准模型（代码名 `static_zero`）。它保留相同的 Linear 和修正规则，唯一区别是 MLP 看不到当前样本的 Linear 结果。

| Dataset | 相对同参数静态对照 | 相对 Linear |
|---|---:|---:|
| Abilene | +1.3413% | +1.8900% |
| GEANT | +0.7437% | +1.1474% |
| A/G structured（seed / dataset 等权） | **+1.0425%** | **+1.5187%** |
| SNDlib BRAIN（协议固定；BRAIN 内训练并锁定 checkpoint 后确认） | **+1.1396%** | **+3.2627%** |

上表的 A/G 主结果为 K=3 structured primary，只含 internal-block 与 two-burst；每个 dataset×seed 内先合并两类 mask，再对 3 个 seed 和 A/G 等权。A/G 两个网络、三个 seed、主要的成段缺失设置均同向。方法结构、超参数和评估规则固定后，使用 BRAIN 自身 fit/source-dev 训练并选择 checkpoint，登记冻结后才打开 confirmation；三个 seed 与两类成段缺失全部为正。这不是 A/G 权重直接 zero-shot 到 BRAIN。

统计复核后，A/G 以同一物理窗口在方法、mask、seed 间共享抽样；约 1/2-day block 下两项 CI 仍完整为正。BRAIN 28/28 窗口同向，但仅覆盖约一天，不能外推长期时间相关性。

### 第 4 页：不是只追 accuracy——成本与异质性

- CalibTM 只有 5,475 参数，一次前向。
- 在当前 H800 完整代码中，ARI latency 是 CalibTM 的 11.17–35.12 倍，显存峰值是 5.75–12.58 倍。
- 单线程 CPU、batch=1 时，CalibTM 在 A/G 为 4.783/17.260 ms；当前 ARI 实现分别慢 283.8/186.9 倍。
- 但 Linear 仍明显更便宜：CPU 上约快 16–23 倍。因此正确结论不是“最低成本且最准”，而是 CalibTM 位于 Linear 与大型模型之间。
- ImputeFormer 在 Abilene 优于 CalibTM、在 GEANT 强烈反转；这一异质性必须保留，不能声称普遍 SOTA。
- 组会 PPT 为方便理解，另把 GEANT、batch=8 的 H800 实测换成 A100 量级估算：Linear 约 0.4–0.6 ms、CalibTM 约 3–5 ms、ARI 约 100–150 ms、ImputeFormer 约 20–40 ms。该区间不是 A100 实测，不用于论文结论。

所有速度数字都只是当前完整代码的实测结果，不代表经过同等工程优化后的架构理论速度，也不冒充官方实现速度。

### 第 5 页：我知道哪些结论还不能说

1. 三个 WAN 的主要 mask 仍是人工 thinning；RIPE 只提供真实 control-plane availability shape 的 semi-synthetic replay，不是 native TM outage。
2. BRAIN 的 OD demand 是从 link measurement 通过优化问题反算得到的，不是直接采集；最终只验证了 28 个窗口。
3. 现有同参数对照只证明“让 MLP 看到当前 Linear 结果”有价值，不能证明有限修正一定优于所有无约束预测。
4. edge head 在同一单侧边界段内产生 distance-invariant 常量修正，是明确的表达力限制。
5. 方法新颖性中等；最危险的审稿意见仍是“Linear + tiny bounded MLP correction”。

这些是论文边界，不是明天需要临时加模型修补的漏洞。

### 第 6 页：接下来两周怎么推进

1. 不再改模型，不再做 KAN、attention、Mamba、router、删头重训或结果驱动的 mask 搜索。
2. 把现有中文 v3 迁入目标会议英文双栏模板，压缩为问题—方法—主证据—限制。
3. 主表保留 A/G/BRAIN per-dataset 结果，不能只报 pooled。
4. 主图同时展示 Linear、同参数静态对照、CalibTM、ARI、ImputeFormer 的精度和成本。
5. 请导师帮助拍板两个问题：目标 venue；是否值得补 1 个输入假设公平的经典 TM baseline。若无法做到同任务/同信息边界，就不为凑数量硬适配。

## 最可能的追问与回答

### “这不就是 Linear 加一个小 MLP 吗？”

回答：

> 从结构上看确实是 Linear 加一个小 MLP，我不主张发明了 interpolation 或 MLP。区别是这个 MLP 不能自由输出：它分别修正中间缺口和两端缺口，修正幅度有限，最后也绝不改变真实观测。论文的价值主要来自对这个特定方案做了同参数公平对照、第三 WAN 验证和真实成本测试，而不是提出了全新的神经网络层。

### “1% 有什么实际意义？”

回答：

> Linear 已经是很强、零训练的基线，所以增益不大。价值不在绝对 SOTA，而在只用 5,475 参数、无需 topology/routing/identity，仍在三个 WAN 对 Linear 和同参数对照稳定改善。同时我会明确展示 Linear 更便宜，让读者自己判断这点精度是否值得额外成本，不把 1% 夸成实际部署收益。

### “为什么不继续加特征/改 edge/删掉无效 head？”

回答：

> 因为这些建议是在看过当前结果后才产生的，而且现在没有一份全新的独立数据可以用来最终检验新版本。继续根据结果反复改模型，很容易重新回到二阶 auto-research。现稿没有声称这些部件必要或最优，所以我选择固定当前方法、诚实写出限制，而不是不断做新版本。

### “你凭什么说 Linear 很强？是否做过 ARI 整体消融？”

回答：

> 我确认的是一个场景限定的事实：在 A/G 的 T=50、K=3 人工缺失协议下，Linear 是有竞争力、难以大幅改进的零训练基线，而不是在所有数据和 mask 下普遍最优。把 random、internal-block 和 two-burst 三类注册 mask 都纳入，在每个网络内合并、对 3 个 seed 等权，再让 Abilene/GEANT 各占 50% 时，Linear NMAE 为 0.227600、按相同指标重跑的 ARI 为 0.229020；但 ARI 在 Abilene 更好，Linear 在 GEANT 更好。CalibTM 在两类 structured masks 的主结果中把 Linear 再改善 1.52%，PCHIP 反而比 Linear 差 1.09%。
>
> 当前 CalibTM 论文不依赖“ARI 主要靠 Linear”或“LLM 无用”的内部归因，所以不需要为了这篇论文展开 ARI 全结构消融。旧诊断只能提供一个线索：有强 Linear 初始结果时 GPT/no-LLM 常常接近，但拿掉这个初始结果后，LLM 在部分设置中又明显有用。如果后续要专门回答 ARI 的组件贡献，我会设计四个严格匹配的模型，分别比较“有/无 Linear 初始填充”和“有/无 LLM”，其余部分保持相同，而不是在汇报前临时关闭模块。

### “真实场景在哪里？”

回答：

> 目前最诚实的回答是：主实验仍是 extreme artificial thinning。我们验证了三个官方 RIPE maintenance availability shapes 的转移，但这只是 control-plane measured-mask semi-synthetic replay，不是 native TM missing trace。BRAIN 是官方 measurement-derived demand archive，但由 link measurement 经 LP 反演。这个现实性缺口会作为 limitation，不会被 synthetic mask 冒充解决。
