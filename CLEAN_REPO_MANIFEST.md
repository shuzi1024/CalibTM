# Clean repository manifest

Created from the working tree on 2026-09-11.

Included: source code for `Imputation/`, the minimal calibrator and Tiny-KAN
experiments with their required internal support packages, selected paper and
protocol documents, tests, and asset-download helpers.

Excluded: all checkpoints and pretrained weights, Hugging Face caches, raw
datasets and archives, generated predictions, result directories, temporary
files, PDFs/PPTX outputs, Python bytecode, and machine-specific runtime
environments. The original 375GB working directory was not modified.

The repository is intended to be pushed as source only. Download data and
weights separately on the GPU server, and verify the licensing terms of each
upstream dataset/model before redistribution.
